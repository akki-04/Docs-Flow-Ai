# DocFlow AI

## Problem Statement

Companies/user manually analyze documents like resumes, invoices, agreements, and reports.
This process is slow and error-prone.

## Solution

DocFlow AI allows users to upload documents, extract structured information using AI, and view the results through a dashboard.

## Target Users

- HR
- Recruiters
- Finance Teams
- Students

## Version 1 Features

- Upload PDF
- Analyze Document
- Ask query to llm
- RAG model gives relavant answer
- Similarity search
- specific user understanding language answer given by this version
- View Result
- Dashboard
